\# 🎓 AI Powered Institute Management \& Learning Platform



\## 📌 Project Overview



AI Powered Institute Management \& Learning Platform is a full-stack web application developed to manage institutes, students, teachers, and courses with AI-powered learning features.



The platform provides separate dashboards for Admin, Teacher, and Student along with authentication, analytics, notifications, attendance, assignments, quizzes, and AI integration.
